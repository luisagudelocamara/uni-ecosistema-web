# uni-ecosistema-web

Versión **publicada, de solo lectura**, del mapa del ecosistema del fomento audiovisual en
Cundinamarca — instrumento de la tesis de maestría de Luis Alfonso Agudelo Ibáñez (Programa
Universidad).

- **Qué hay aquí:** un solo archivo, `index.html`, generado desde el vault privado del Programa.
- **Qué no hay aquí:** el vault, las matrices, las lecturas, nada marcado `clase` ni
  `material-docente`. Este repo es la proyección, no la fuente.
- **Quién lo actualiza:** Luis, desde su editor local, con el botón **Publicar**
  (`scripts/publicar.py` en `uni-knowledge`). Cada publicación pasa el verificador de integridad
  y un chequeo de privacidad antes de salir.
- **Dónde se ve:** desplegado en Vercel desde este repo (rama `main`). Cada push publica.

Nada se edita en este repo a mano.
